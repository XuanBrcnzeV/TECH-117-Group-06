Traffic Light Warning System

An intelligent real-time proximity and driver alert system powered by an Arduino Uno, HC-SR04 ultrasonic sensor, LED indicators, and a multi-frequency passive buzzer—designed to prevent red-light running, reduce intersection collisions, and enhance road safety in low-visibility conditions.

2. Introduction, Goals & Success Criteria

Intersections are among the most high-risk areas on modern roadways due to sudden signal transitions, driver distraction, and adverse weather conditions such as fog or heavy rain. Our Traffic Light Warning System addresses this safety gap using an Arduino Uno, an HC-SR04 ultrasonic sensor, a passive buzzer, and Red/Yellow/Green LEDs to detect proximity and upcoming signal states, delivering timely visual and auditory warnings so drivers have sufficient reaction time to decelerate safely.

🎯

Project Goals (System Intent)

  • • Real-Time Signal & Proximity Detection: Accurately identify traffic light states (Green, Yellow, Red) and approach distances prior to the vehicle reaching the intersection stop line.
  • • Timely Multi-Modal Driver Alerts: Deliver clear visual dashboard LED indicators and distinct audio chimes (300 Hz caution / 500 Hz stop) to warn drivers of impending Yellow or Red lights.
  • • Intersection Safety Enhancement: Reduce late hard-braking and unintentional red-light violations during distracted driving or low-visibility weather.
✅

Success Criteria (Measurable KPIs)

  • • Detection Accuracy (≥ 95%): The prototype reliably classifies Green (> 30 cm), Yellow (11–30 cm), and Red (≤ 10 cm) alert zones across 50 consecutive test runs.
  • • Alert Latency (< 0.5 seconds): End-to-end system response time from ultrasonic echo or signal transition to LED/buzzer activation remains under 500 ms.
  • • User Comprehension (≥ 85%): At least 85% of test participants immediately distinguish caution vs. stop warnings without confusion during usability trials.

3. Project Constraints, Risks & Contingency Plans

📌 Engineering Constraints

  • Time Constraint: The single-semester schedule limits physical validation to controlled tabletop scale models rather than live public roadway deployments.
  • Budget Constraint: A strict student hardware budget (~$42 USD) precludes expensive commercial DSRC / C-V2X (Vehicle-to-Everything) transceivers.
  • Resources & Skills: Limited access to outdoor testing tracks and varying levels of embedded C++ programming experience across the four team members.

⚠️ Identified Risks & Backup Plans

  • Risk 1 — Ambient Glare & Acoustic Echo Noise: Stray reflections or background lighting may trigger erratic readings.
    Backup Plan: Filter invalid readings (distance <= 0) in firmware and conduct primary demonstrations under controlled indoor lighting.
  • Risk 2 — Hardware Failure or Shipping Delays: Sensors or jumper connections may loosen or fail prior to demo day.
    Backup Plan: Maintain the interactive web-based simulator below to demonstrate exact threshold logic and audio tones on schedule.
  • Risk 3 — Scope Creep: Adding complex multi-lane wireless networking could jeopardize core reliability.
    Backup Plan: Lock core ultrasonic proximity and 3-state LED/buzzer alert deliverables first before attempting stretch enhancements.

5. Circuit Diagram & Hardware Pinout

The HC-SR04 ultrasonic sensor continuously measures obstacle distance using 40 kHz acoustic pulses. Based on the computed distance in centimeters, the Arduino Uno switches the corresponding Red, Yellow, or Green LED (protected by 220 Ω current-limiting resistors) and drives the passive piezo buzzer via PWM tones.

6. Environmental Impact Assessment

The Arduino Uno Rev3 and passive components are RoHS and WEEE compliant, restricting lead, mercury, and hazardous heavy metals.

9. Arduino C++ Firmware Code

Controls LED signal indicators and passive buzzer frequencies based on HC-SR04 distance thresholds.

// Traffic Light & Collision Warning System with Distance Sensor (HC-SR04)
// Course: TECH 117 — Group 06 (Xuan, Tyler, Michael, Jide)
// Object is farther than 30cm: Green LED lights up
// Object is closer than 30cm, but more than 10cm away: Yellow LED lights, buzzer plays 300Hz tone
// Object is closer than 10cm: Red LED lights up, buzzer plays 500Hz tone

// LED pins
const int greenLED = 2;
const int yellowLED = 3;
const int redLED = 4;

// Ultrasonic sensor pins
const int trigPin = 9;
const int echoPin = 10;

// Passive buzzer pin
const int buzzer = 11;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Measure distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  long distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  
  // Error in measurement:
  if (distance <= 0)
    return;

  // Too close (Red Light Warning):
  if (distance <= 10) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    tone(buzzer, 500); // Play 500Hz tone
    return;
  }

  // Midrange (Yellow Caution Warning):
  if (distance <= 30) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    tone(buzzer, 300); // Play 300Hz tone
    return;
  }

  // Normal status (Green Clear):
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  noTone(buzzer); // stop buzzer

  delay(100);
}

10. Conclusion

The Traffic Light Warning System effectively demonstrates real-time proximity and signal state alerting using an Arduino Uno, ultrasonic distance sensing, and multi-frequency auditory feedback. At a total component cost of $41.64, the system provides an affordable, educational, and environmentally sustainable prototype capable of helping drivers anticipate stop-line hazards and avoid intersection collisions.
